---
name: Neuro observatory telemetry
description: Durable guidance for the standalone futuristic observatory and its telemetry boundary.
---

The observatory should distinguish server runtime telemetry from browser-local demo animation, and camera/hand tracking must remain opt-in with pointer/touch fallback.

**Why:** The imported project is a no-build static site, while the requested futuristic surface is an independent operator view; transparent data provenance prevents animated visuals from being mistaken for platform-wide production metrics.

**How to apply:** Preserve the relative telemetry endpoint contract and clearly identify any future Firebase or external-service readings by source. Keep camera permissions gated behind an explicit user action.
